# AI Engineer Interview Notes

## Why these projects help

These sample projects are intentionally small, practical, and easy to explain in a recruiter or interview setting. They show that you understand:

- prompt design and chains
- LLM orchestration basics
- retrieval and lookup patterns
- simple project structuring and GitHub hygiene

## Good interview talking points

### 1. LangGraph workflow demo
- Demonstrates workflow orchestration with multiple states
- Useful for explaining how AI systems can sequence tasks logically
- Easy to scale into a more complex agent pipeline

### 2. Mini RAG demo
- Shows retrieval logic and document matching
- Explains the difference between a retriever and a generator
- Good way to talk about grounding model answers with external context

### 3. Prompt pipeline demo
- Shows how to split tasks into classification, generation, and formatting
- Demonstrates practical prompt design without needing a heavy app stack

## Resume-friendly project framing

Use simple summaries such as:

- "Built a LangGraph-based workflow prototype for a multi-step AI system"
- "Implemented a RAG-style retrieval demo using TF-IDF similarity search"
- "Created a prompt orchestration pipeline to classify user intent and generate structured answers"

These are realistic examples of AI engineering fundamentals and show forward motion without needing a large production project.
